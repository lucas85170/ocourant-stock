# O’Courant Stock — Projet iOS natif

Structure du projet :
- `OCourantStock.xcodeproj/` : dossier de projet Xcode contenant `project.pbxproj`
- `OCourantStock/OCourantStockApp.swift` : code SwiftUI de l’application
- `codemagic.yaml` : workflow de vérification/compilation Codemagic

## Important
Ce projet source n'est pas un fichier `.ipa`. Pour obtenir un `.ipa` installable, une signature Apple valide et un profil de provisionnement adaptés sont nécessaires. Avec un compte Apple gratuit, l'installation personnelle est limitée dans le temps; la création d'un IPA distribuable durable n'est pas garantie.
